# 자동차사고 과실비율 인정기준 (2023.6.30) — RAG용 청크

원본: `../230630_자동차사고 과실비율 인정기준_최종.pdf` (600쪽)

## 구성

| 파일 | 용도 |
|---|---|
| `chunks.jsonl` | 벡터DB 적재용. 한 줄에 청크 하나 (`id`, `text`, 메타데이터) |
| `chunks/*.md` | 파일 기반 에이전트용. YAML front matter + 본문 |
| `index.md` | 전체 청크 목록 (유형코드 → 파일). 에이전트가 먼저 훑어볼 목차 |
| `build_chunks.py` | 재생성 스크립트 (`python build_chunks.py <원본.pdf> <출력폴더>`, pypdf·cryptography 필요) |

## 청크 기준

- **사고유형별 기준(163개)**: 사고유형 코드(보1, 차1-1, 거1-1 …) 하나가 청크 하나입니다. 한 쪽에 함께 실린 유형(예: 보3·보4)은 한 청크로 묶었습니다. 청크에는 기본 과실비율, 수정요소, 사고 상황, 해설, 관련 법규, 참고 판례가 들어 있습니다.
- **총설·적용범위·용어정의·수정요소 해설**: 목차 소제목 단위로 나눴습니다.
- 7,000자를 넘는 섹션은 쪽 경계에서 `part 1/N`으로 나눴습니다.
- 목차(1~6쪽)는 `index.md`로 대신해서 따로 넣지 않았습니다.

## 메타데이터

| 필드 | 설명 |
|---|---|
| `codes` | 사고유형 코드 목록. 정확히 일치하는 값으로 필터링할 때 씁니다 (예: 사용자가 "차43-2"를 물을 때) |
| `category` | 자동차-보행자 / 자동차-자동차 / 자동차-자전거 |
| `doc_type` | 사고유형별 기준, 총설, 수정요소 해설, 적용범위·용어정의, 변경대비표, 발간사, 개정경과 |
| `section_path` | 목차 경로 (편 > 장 > 절 > 항) |
| `pdf_pages` / `printed_pages` | PDF 쪽 번호 / 책에 인쇄된 쪽 번호 (인쇄 쪽 = PDF 쪽 − 1). 출처를 표시할 때 씁니다 |

임베딩할 때 문맥이 들어가도록, 각 `text` 맨 앞에 문서명·목차 경로·사고유형 제목을 넣었습니다.

## 한계

- 사고 도표(그림)는 이미지라서 텍스트에 들어 있지 않습니다. 그림 속 라벨만 일부 추출됩니다. 그림이 필요하면 `pdf_pages`로 원본을 찾아보세요.
- 표는 행 단위 텍스트로 풀려 있어서 칸 정렬이 일부 흐트러질 수 있습니다.
- `변경대비표`는 개정 전후를 비교한 표입니다. 현행 기준만 답해야 한다면 `doc_type != "변경대비표"`로 걸러내세요.
